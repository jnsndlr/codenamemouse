# Codename: Mouse — application icons

Generated from `app-icon-master.png` for desktop export and store listings.

## Godot export fields

- Project icon: `res://assets/branding/png/app-icon-1024.png`
- Windows icon: `res://assets/branding/codename-mouse.ico`
- macOS icon: `res://assets/branding/codename-mouse.icns`

## PNG sizes

The `png/` directory contains 16, 32, 48, 64, 128, 256, 512, and 1024 px
square versions. Use the 512 or 1024 px version for launcher and store artwork;
use the smaller files only where a platform specifically requests them.

The source artwork intentionally contains no text so it remains readable at
small sizes and can be reused across platforms.
